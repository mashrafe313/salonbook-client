
# SalonBook - Client

SalonBook is a salon appointment booking platform
where customers can explore salon services, request
appointments, manage bookings, and make payments.

## Technology Stack

- Next.js
- TypeScript
- React
- Tailwind CSS
- Better Auth

## Main Features

- Browse salon services
- Search and filter services
- Service details
- Customer authentication
- Admin and customer dashboards
- Appointment booking
- Stripe payment integration
- Responsive user interface

## Environment Variables

- BETTER_AUTH_SECRET
- BETTER_AUTH_URL
- MONGODB_URI
- GOOGLE_CLIENT_ID
- GOOGLE_CLIENT_SECRET
- NEXT_PUBLIC_API_URL

## Installation

npm install

## Run Locally

npm run dev
